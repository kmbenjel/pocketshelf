# التثبيت

pocketshelf أداة بايثون صغيرة (نحو 170 كيلوبايت) لا تعتمد على أي حزمة أخرى. تحتاج بايثون 3.10 أو أحدث فقط.

## بأمر واحد بلا تثبيت دائم

```bash
uvx pocketshelf build ~/Books
```

يشغّل `uvx` الأداة في بيئة مؤقتة ثم يتركها. إن لم يكن عندك `uv` فاستعمل `pipx`.

## تثبيت دائم

```bash
pipx install pocketshelf
```

أو بـ pip في بيئة افتراضية:

```bash
python -m venv .venv
.venv/bin/pip install pocketshelf
```

## التحقق من التثبيت

```bash
pocketshelf --version
pocketshelf demo --open
```

الأمر الثاني يبني فهرسًا تجريبيًا من بيانات للملك العام (مكتبة مشروع غوتنبرغ ومختارات من التراث العربي) ويفتحه في المتصفح.

!!! note "ملاحظة"
    لا يحتاج الفهرس الناتج إلى بايثون ولا إلى خادم. بعد البناء يصبح ملف HTML واحدًا تفتحه أي متصفح حديث.

## قراءة مزيد من البيانات الوصفية

القراءة من ملفات PDF وEPUB مدمجة في الأداة نفسها. وإن ثبّتَّ حزمة `arabic-bib` فسيستعملها `--profile warraq` تلقائيًا لتحليل أسماء الملفات العربية تحليلًا أدق، دون أي إعداد:

```bash
pipx inject pocketshelf arabic-bib
```
