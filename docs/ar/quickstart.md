# البدء السريع

## 1. جرّب العرض التجريبي

```bash
pocketshelf demo --arabic --open
```

يُنشأ ملف `pocketshelf-demo.html` فيه 95 كتابًا من أمهات التراث، ويُفتح في المتصفح. جرّب في خانة البحث `احياء علوم` فيظهر «إحياء علوم الدين»: البحث لا يفرّق بين الهمزات ولا بين التاء المربوطة والهاء، ولا يتأثر بالتشكيل.

## 2. ابنِ فهرس مكتبتك

```bash
pocketshelf build ~/Books --lang ar
```

يمسح الأمر المجلد (وما تحته) بحثًا عن PDF وEPUB وDJVU، ويقرأ عنوان كل ملف ومؤلفه من داخل الملف إن وُجد وإلا من اسمه، ثم يكتب `~/Books/pocketshelf.html`.

!!! tip "نصيحة"
    ضع الملف الناتج في جذر المكتبة نفسها. الروابط داخله نسبية، فتبقى صالحة ما دام الفهرس بجانب الكتب، حتى لو نسخت المجلد كله إلى هاتفك أو إلى قرص خارجي.

## 3. انقله إلى الهاتف وافتحه

انسخ المجلد (الكتب والفهرس معًا) إلى ذاكرة الهاتف، ثم افتح `pocketshelf.html` من تطبيق الملفات بمتصفح مثل Chrome أو Brave. لا إنترنت ولا خادم. انظر [الفتح على أندرويد](guides/android.md).

## 4. صحّح ما أخطأ فيه الاستنتاج

إن كانت أسماء ملفاتك على نسق معيّن فاذكره:

```bash
pocketshelf build ~/Books --template '{author} - {title} ({year})'
```

أو صدّر البيانات إلى جدول، عدّلها في أي برنامج جداول، وأعد البناء بها:

```bash
pocketshelf scan ~/Books -o books.csv
pocketshelf build ~/Books --sidecar books.csv
```

التفاصيل في [أسماء الملفات والقوالب](guides/filenames.md) و[الجدول المساعد](guides/sidecar.md).
