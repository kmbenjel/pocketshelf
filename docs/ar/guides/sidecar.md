# الجدول المساعد (sidecar)

أسهل طريق لتصحيح البيانات هو جدول CSV تعدّله في أي برنامج جداول.

```bash
pocketshelf scan ~/Books -o books.csv
```

افتح `books.csv`، وصحّح الأعمدة التي تريد (`title` و`author` و`author_death` و`category` …)، واحفظه بترميز UTF-8. ثم:

```bash
pocketshelf build ~/Books --sidecar books.csv
```

تُطابَق الصفوف بعمود `path`، وتتقدّم الحقول غير الفارغة في الجدول على ما استُنتج من الملفات.

## سنة الوفاة والقرون

عمودا `author_death` و`author_calendar` (`ah` للهجري، `ce` للميلادي) يغذّيان تبويب «المؤلفون» الذي يجمع المؤلفين حسب القرن الهجري أو الميلادي.

## فهرس بلا ملفات

يمكنك بناء فهرس من جدول فقط، دون مجلد كتب (قائمة مراجع، أو فهرس مكتبة تخطط لاقتنائها):

```bash
pocketshelf build catalog.csv -o catalog.html --lang ar
```

الأعمدة كلها في [مواصفة الجدول](https://github.com/kmbenjel/pocketshelf/blob/main/docs/catalog-schema.md).

## الطبعات

اكتب في عمود `work` معرّفًا واحدًا للصفوف التي هي طبعات لكتاب واحد، فتُجمع في بطاقة واحدة تُعرض طبعاتها عند فتحها. فإن تركته فارغًا جمع pocketshelf الصفوف التي يتفق عنوانها واسم مؤلفها بعد توحيد الحروف.
