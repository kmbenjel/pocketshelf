# أسماء الملفات والقوالب

يقرأ pocketshelf البيانات من ثلاثة مصادر مرتبة: **الجدول المساعد**، ثم **داخل الملف** (حقول PDF وEPUB)، ثم **اسم الملف**. وغالبًا تكون حقول PDF فارغة أو رديئة («Microsoft Word - doc1») فيسقطها ويرجع إلى الاسم.

## القالب

اكتب نسق اسم ملفاتك بحقول بين أقواس معقوصة:

```bash
pocketshelf build ~/Books --template '{author} - {title} ({year})'
```

الحقول: `title` `author` `editor` `publisher` `place` `year` `series` `edition` `volume` `lang` و`skip` لما تريد تجاهله. يمكنك تكرار `--template`؛ يؤخذ أول قالب يطابق.

## الملفات العربية: نسق «ورّاق»

```bash
pocketshelf build ~/Books --profile warraq
```

يفهم النسق `العنوان - المؤلف - ت المحقق - الناشر المدينة`، وأرقام الأجزاء `01 - اسم الكتاب`، وسنة الوفاة في اسم المؤلف مثل `ابن تيمية ت 728`. وإن ثبّتَّ حزمة `arabic-bib` استعملها pocketshelf تلقائيًا لتحليل أدق.

## تجربة اسم واحد

```bash
pocketshelf inspect "~/Books/المغني - ابن قدامة.pdf" --profile warraq
```

يطبع ما قُرئ من الاسم وما قُرئ من داخل الملف، فتعرف سبب أي خطأ قبل بناء الفهرس كله.

## الأجزاء

الملفات المرقّمة في مجلد واحد (`01 - …` و`02 - …`، أو `ج1` و`ج2`، أو `vol 1`) تُجمع كتابًا واحدًا متعدد الأجزاء، اسمه اسم المجلد. وإن لم ترد ذلك فمرّر `--no-volume-groups`.
